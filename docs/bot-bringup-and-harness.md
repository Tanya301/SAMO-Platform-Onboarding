# Bot and Telegram Bring-Up (operator)

Bring-up is manual today:

1. Provision one OpenClaw bot for the client project.
2. Give it this handbook and its completed private assignment.
3. Confirm access to the client repo and any in-scope infrastructure.
4. Create the Telegram group, add the bot, and connect the group to the project.
5. Confirm the bot can see the repo and issues, reply in Telegram, and state its
   assignment correctly.
6. Confirm the preview safety facts.
7. Send the [existing-app kickoff](client-welcome-message.md), or the
   project-specific kickoff recorded for a brand-new app.

There is no one-button provisioning or workflow enforcement yet. Those ideas
belong in [Open Questions](../OPEN-QUESTIONS.md); they are not prerequisites for
using this handbook.
